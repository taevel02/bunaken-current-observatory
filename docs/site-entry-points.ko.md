# 대표 입수점 좌표

2026-09-30 사용자가 웹 지도와 부나켄에서의 다이빙 경험을 대조하여 19개 Site의 대표 입수점 좌표를 확정했다. 보트 상황에 따라 실제 입수점은 달라질 수 있다. 좌표는 다이빙 경로 전체나 Zone 경계를 의미하지 않는다.

`config/geometry.json` schema_version 1.1의 `coordinates_verified`는 lat/lon만 확인된 상태다. 기존 1.0의 `unverified`와 전체 geometry의 `verified`도 읽기 호환한다. 좌표는 `packages/contracts/data/sites.json`과 동일하게 유지한다. 도·분·초 입력은 `degrees + minutes / 60 + seconds / 3600`으로 변환하여 소수점 6자리로 저장했다. 확인 날짜는 날짜 정밀도로 보존하며 측정 시각이나 GPS 오차를 추정하지 않는다.

사용자의 `ok`는 직전 좌표 검토 표의 첫 번째 후보를 승인한 것으로 반영했다. 특히 Mike’s Point는 1.636833, 124.739722이며, Alung Banua는 1.616667, 124.753194다. 사용자가 별도 제시한 좌표는 해당 후보를 대체했다.

전체 geometry를 `verified`로 승격하려면 기준 수심, true-north 벽/외해 방향, 허용 격자 거리와 근거가 추가로 필요하다. `coordinates_verified`만으로 운영 수집 또는 방향 투영을 허용하지 않는다. 좌표에 따른 실제 공급 격자 확인은 별도 진단이며 대표 수심이나 허용 거리를 자동 확정하는 근거가 아니다.

기존 `environment-sources.ko.md`의 좌표 미확정 설명은 이 결정 이전 상태다. 사용자 요청에 따라 해당 문서는 변경하지 않았다.
